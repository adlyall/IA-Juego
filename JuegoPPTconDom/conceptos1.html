📦 1. Variables: let y const

Las variables almacenan datos que el programa usa. En JavaScript moderno usamos dos palabras reservadas:

💡 Diferencia clave:
  • let → el valor puede cambiar (reasignable)
  • const → el valor NO puede cambiar (constante)

En clase10.js (líneas 1-15):

// ARRAY constante: las jugadas no cambian
const jugadas = ["Piedra ✊", "Papel ✋", "Tijera ✌️"];

// OBJETO con let: los puntajes SÍ cambian
let puntajes = {
    usuario: 0,
    computadora: 0,
    empates: 0
};

// Variables con let: valores que cambian
let nombreJugador = "";
let numeroRonda = 0;

Reasignación con let:

numeroRonda = 0;      // valor inicial
numeroRonda = 1;      // se puede cambiar
numeroRonda++;        // incrementa en 1 (ahora vale 2)

// Con const NO se puede:
// jugadas = ["otro"];  // ERROR: no se puede reasignar

🔀 2. Condicionales: if / else

Los condicionales permiten tomar decisiones según una condición. El código dentro del if se ejecuta solo si la condición es verdadera.

En clase10.js — Validación de nombre (líneas 26-39):

// Si el usuario cancela el prompt (null)
if (nombre === null) {
    alert("El nombre es obligatorio para jugar.");
    continue;  // vuelve a pedir el nombre
}

// Si tiene menos de 3 caracteres
if (nombre.length < 3) {
    alert("El nombre debe tener al menos 3 caracteres.");
    continue;  // vuelve a pedir el nombre
}

En clase10.js — Comparar jugadas (líneas 91-108):

function compararJugadas(jugadaUsuario, jugadaComputadora) {
    // Si son iguales → empate
    if (jugadaUsuario === jugadaComputadora) {
        return "empate";
    }

    // Si el usuario gana (3 casos posibles)
    if (
        (jugadaUsuario === 1 && jugadaComputadora === 3) ||
        (jugadaUsuario === 3 && jugadaComputadora === 2) ||
        (jugadaUsuario === 2 && jugadaComputadora === 1)
    ) {
        return "usuario";
    }

    // Si no es empate ni gana el usuario → gana la computadora
    return "computadora";
}
💡 Operadores usados:
  • === → igual estricto (mismo valor Y tipo)
  • !== → distinto estricto
  • && → AND (ambas condiciones verdaderas)
  • || → OR (al menos una verdadera)

⚙️ 3. Funciones: parámetros y return

Las funciones son bloques de código reutilizables. Reciben datos (parámetros) y pueden devolver un resultado (return).

En clase10.js — Función con parámetros y return (líneas 50-58):

// FUNCIÓN: genera número aleatorio entre 1 y 3
function jugadaRandom() {
    let numeroAleatorio = Math.floor(Math.random() * 3) + 1;
    return numeroAleatorio;  // devuelve 1, 2 o 3
}

En clase10.js — Función con parámetros (líneas 91-108):

// FUNCIÓN: recibe dos parámetros y devuelve el resultado
function compararJugadas(jugadaUsuario, jugadaComputadora) {
    if (jugadaUsuario === jugadaComputadora) {
        return "empate";        // devuelve string
    }
    if (/* condiciones de victoria */) {
        return "usuario";       // devuelve string
    }
    return "computadora";       // devuelve string
}

Cómo se usan (línea 189):

// Llamada a la función con argumentos
let resultado = compararJugadas(jugadaUsuario, jugadaComputadora);
// resultado ahora vale: "usuario", "computadora" o "empate"
💡 Parámetro vs Argumento:
  • Parámetro → variable en la definición: function foo(x)
  • Argumento → valor real al llamar: foo(5)

📚 4. Arrays

Un array es una lista ordenada de valores. Cada posición tiene un índice que empieza en 0.

En clase10.js (línea 1):

// ARRAY: contiene las posibles jugadas
const jugadas = ["Piedra ✊", "Papel ✋", "Tijera ✌️"];

// Índices:      0            1          2

Acceder a un elemento por índice:

jugadas[0]  // "Piedra ✊"
jugadas[1]  // "Papel ✋"
jugadas[2]  // "Tijera ✌️"

// En el juego (línea 124):
jugadas[jugadaUsuario - 1]
// Si jugadaUsuario = 1 → jugadas[0] → "Piedra ✊"
// Si jugadaUsuario = 2 → jugadas[1] → "Papel ✋"
// Si jugadaUsuario = 3 → jugadas[2] → "Tijera ✌️"
💡 ¿Por qué - 1?

El usuario ingresa 1, 2 o 3. Pero los índices del array empiezan en 0. Por eso se resta 1 para convertir la entrada del usuario al índice correcto del array.

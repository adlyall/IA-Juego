📖 ¿Qué es el DOM?

El DOM (Document Object Model) es la representación en árbol del documento HTML. Permite a JavaScript leer, modificar, crear y eliminar elementos de la página web dinámicamente.

En este juego utilizamos el DOM de forma mínima y educativa: solo para vincular botones a funciones y en la pantalla de victoria (ganador.html) para mostrar datos dinámicos.

🔗 1. Seleccionar elementos: getElementById y querySelector

Antes de manipular un elemento, debemos seleccionarlo.

En clase10.js (línea 230):

// Selecciona el botón por su ID
document.getElementById("btnIniciar")

En ganador.js (líneas 11-22):

// Por ID (único)
const winnerTitle = document.getElementById('winnerTitle');
const winnerName = document.getElementById('winnerName');

// Por selector CSS (clase, etiqueta, etc.)
const statsCard = document.getElementById('statsCard');
const buttonGroup = document.querySelector('.button-group');
💡 Diferencia clave:
  • getElementById('id') → Un solo elemento (rápido, único)
  • querySelector('.clase') → Primer match de selector CSS
  • querySelectorAll('.clase') → Todos los matches (NodeList)

🎯 2. Eventos: addEventListener

Los eventos permiten reaccionar a acciones del usuario (click, teclado, carga de página, etc.).

En clase10.js (líneas 229-232):

// Evento click en el botón iniciar
document.getElementById("btnIniciar").addEventListener("click", function() {
    iniciarJuego();
});

En ganador.js (líneas 47-60 y 82-102):

// Evento: página cargada (DOM listo)
document.addEventListener('DOMContentLoaded', function() {
    statsCard.style.opacity = '0';
    buttonGroup.style.opacity = '0';
    
    setTimeout(() => {
        statsCard.style.animation = 'slideUp 0.6s ease-out';
        statsCard.style.opacity = '1';
    }, 200);
});

// Evento: click en botón borrar
const btnBorrarStats = document.getElementById('btnBorrarStats');
btnBorrarStats.addEventListener('click', function() {
    totalRondasEl.textContent = '0';
    // ... más código
});
💡 Eventos usados en el proyecto:
  • click → Botones "INICIAR PARTIDA", "BORRAR ESTADÍSTICAS"
  • DOMContentLoaded → Animaciones de entrada en ganador.html

✏️ 3. Modificar contenido: textContent e innerHTML

Cambiar el texto o HTML interno de un elemento.

En ganador.js (líneas 24-38):

// textContent: solo texto (seguro, escapa HTML)
winnerTitle.textContent = '🏆 ¡GANADOR!';
winnerName.textContent = nombreJugador;  // Variable dinámica
winnerMessage.textContent = 'Ha derrotado a la computadora';

Actualizar estadísticas (líneas 41-45):

totalRondasEl.textContent = totalRondas;
victoriasUsuarioEl.textContent = puntajeUsuario;
victoriasComputadoraEl.textContent = puntajeComputadora;
empatesEl.textContent = empates;

Feedback visual en botón borrar (líneas 91-94):

this.textContent = '✅ BORRADO';  // Cambia texto del botón
💡 textContent vs innerHTML:
  • textContent → Solo texto, seguro contra XSS, rápido
  • innerHTML → Permite HTML, peligroso si datos vienen del usuario
  • En este proyecto solo usamos textContent por seguridad

🎨 4. Modificar estilos: style property

Cambiar CSS dinámicamente desde JavaScript.

En ganador.js - Animaciones (líneas 48-59):

statsCard.style.opacity = '0';
statsCard.style.animation = 'slideUp 0.6s ease-out';
statsCard.style.opacity = '1';

buttonGroup.style.animation = 'slideUp 0.6s ease-out';
buttonGroup.style.opacity = '1';

Borde dinámico según ganador (líneas 31 y 38):

// Usuario gana → borde verde
winnerCard.style.borderLeft = '6px solid #4ade80';

// Computadora gana → borde rojo
winnerCard.style.borderLeft = '6px solid #f87171';

Feedback visual botón (líneas 92-99):

this.style.background = 'linear-gradient(135deg, #4ade80 0%, #22c55e 100%)';
this.style.boxShadow = '0 4px 20px rgba(74, 222, 128, 0.5)';

// Restaurar después de 1.5s
setTimeout(() => {
    this.style.background = '';
    this.style.boxShadow = '';
}, 1500);
💡 Notas importantes:
  • Propiedades CSS en JS usan camelCase: borderLeft, boxShadow, backgroundColor
  • Valores como strings: '6px solid #4ade80'
  • Asignar '' (vacío) → vuelve al CSS original

🏗️ 5. Crear elementos dinámicamente: createElement + appendChild

Crear nuevos nodos HTML e insertarlos en el árbol DOM.

En ganador.js - Efecto confeti (líneas 63-75):

function crearConfeti() {
    const colores = ['#667eea', '#764ba2', '#4ade80', '#f87171', '#fbbf24'];
    
    for (let i = 0; i < 30; i++) {
        // 1. CREAR elemento
        const confeti = document.createElement('div');
        
        // 2. CONFIGURAR propiedades
        confeti.className = 'confeti';
        confeti.style.left = Math.random() * 100 + '%';
        confeti.style.backgroundColor = colores[Math.floor(Math.random() * colores.length)];
        confeti.style.animationDelay = Math.random() * 2 + 's';
        confeti.style.animationDuration = (2 + Math.random() * 2) + 's';
        
        // 3. INSERTAR en el DOM
        document.body.appendChild(confeti);
        
        // 4. LIMPIAR después de la animación
        setTimeout(() => confeti.remove(), 4000);
    }
}
💡 Flujo de creación dinámica:
  1. document.createElement('tag') → Crea nodo en memoria
  2. Configurar: className, style, textContent, etc.
  3. padre.appendChild(hijo) → Inserta en el árbol (visible)
  4. nodo.remove() → Elimina del DOM (limpieza)

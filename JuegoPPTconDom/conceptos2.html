🎯 1. Objetos: puntajes

Un objeto es una colección de propiedades con nombre. Permite agrupar datos relacionados en una sola variable.

En clase10.js (líneas 4-9):

// OBJETO: almacena los puntajes de la partida
let puntajes = {
    usuario: 0,
    computadora: 0,
    empates: 0
};

Acceder y modificar propiedades:

// Leer una propiedad
puntajes.usuario        // 0 (valor inicial)
puntajes.computadora    // 0
puntajes.empates        // 0

// Modificar una propiedad (acumulador)
puntajes.usuario++;      // suma 1 a usuario
puntajes.computadora++;  // suma 1 a computadora
puntajes.empates++;      // suma 1 a empates

En clase10.js — Actualización (líneas 111-119):

function actualizarPuntajes(resultado) {
    if (resultado === "usuario") {
        puntajes.usuario++;       // acumulador
    } else if (resultado === "computadora") {
        puntajes.computadora++;   // acumulador
    } else {
        puntajes.empates++;       // acumulador
    }
}
💡 Sintaxis de objeto:
  • objeto.propiedad → punto para acceder
  • objeto["propiedad"] → corchetes (alternativa)
  • Las propiedades se separan con comas
  • Última propiedad puede tener coma final (trailing comma)

🔄 2. Ciclos: while y do...while

Los ciclos repiten código mientras una condición sea verdadera.

En clase10.js — Ciclo while para validar nombre (líneas 22-42):

// CICLO: repite hasta que el nombre sea válido
while (!nombreValido) {
    let nombre = prompt("Ingresá tu nombre:");

    if (nombre === null) {
        alert("El nombre es obligatorio.");
        continue;  // salta a la siguiente iteración
    }

    nombre = nombre.trim();

    if (nombre.length < 3) {
        alert("Mínimo 3 caracteres.");
        continue;
    }

    nombreValido = true;  // condición para salir del ciclo
}

En clase10.js — Ciclo while para la partida (líneas 214-217):

// CICLO: mantiene la partida activa hasta que alguien gane
while (puntajes.usuario < 2 && puntajes.computadora < 2) {
    jugarRonda();
}
// Se repite hasta que usuario O computadora lleguen a 2 victorias

En clase10.js — Ciclo while para validar jugada (líneas 65-85):

// CICLO: repite hasta que la jugada sea válida
while (!entradaValida) {
    let entrada = prompt("Elegí: 1-Piedra, 2-Papel, 3-Tijera");

    if (entrada === null) {
        alert("Debés elegir una opción.");
        continue;
    }

    eleccion = Number(entrada);

    if (isNaN(eleccion) || eleccion < 1 || eleccion > 3) {
        alert("Opción inválida.");
        continue;
    }

    entradaValida = true;  // sale del ciclo
}
💡 while vs do...while:
  • while (condición) → evalúa antes, puede no ejecutarse nunca
  • do { } while (condición) → ejecuta al menos una vez, evalúa después
  • En este proyecto usamos while porque la condición se puede verificar antes de pedir datos

🎲 3. Math.random()

Genera un número aleatorio decimal entre 0 (inclusive) y 1 (exclusivo). Se usa para que la computadora elija su jugada de forma impredecible.

En clase10.js (líneas 50-58):

// FUNCIÓN: genera jugada aleatoria para la computadora
function jugadaRandom() {
    // Math.random() → número entre 0 y 0.999...
    // * 3 → número entre 0 y 2.999...
    // Math.floor() → redondea hacia abajo: 0, 1, 2
    // + 1 → desplazamos el rango: 1, 2, 3
    let numeroAleatorio = Math.floor(Math.random() * 3) + 1;
    return numeroAleatorio;
}

Desglose paso a paso:

Math.random()           // 0.7234... (ejemplo)
Math.random() * 3       // 2.1702... (ejemplo)
Math.floor(2.1702)      // 2 (redondea hacia abajo)
Math.floor(...) + 1     // 3 (resultado final)

// Otros ejemplos:
// 0.1234 * 3 = 0.3702 → floor = 0 → +1 = 1 (Piedra)
// 0.5000 * 3 = 1.5000 → floor = 1 → +1 = 2 (Papel)
// 0.9999 * 3 = 2.9997 → floor = 2 → +1 = 3 (Tijera)
💡 Fórmula general:

Math.floor(Math.random() * cantidad) + minimo

  • cantidad → cuántos valores posibles (3 en este juego)
  • minimo → valor más bajo deseado (1 en este juego)
